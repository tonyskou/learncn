# 📖 Μαθαίνω! — 希腊语学习与拼读应用

一款免费、离线可用的 PWA 应用，专为学习希腊语阅读与拼读设计。包含 **3170 个单词**（317 个主题词组），每个希腊语单词上方都有中文释义，配有语音拼读功能，并通过 Firebase 实现云端进度同步。

---

## 📲 在手机上使用

打开应用链接后：

| 设备 | 操作方法 |
|---|---|
| **Android** | 用 **Chrome** 打开链接 → 点击右上角 ⋮ → 「添加到主屏幕」 |
| **iPhone / iPad** | 用 **Safari** 打开链接 → 点击分享按钮 (□↑) → 「添加到主屏幕」 |

添加后，应用会像普通 App 一样出现在主屏幕上，之后**即使没有网络也能正常使用** 📴

---

## 🔐 登录与云端同步

首次打开应用会看到登录界面：

1. 点击 **"创建账户"** → 输入邮箱和密码（至少6位字符），或直接点击 **"使用 Google 登录"**
2. 登录后会直接进入主菜单，学习进度会自动保存
3. 在其他设备上用**相同账号**登录，进度会自动同步
4. 也可以点击 **"跳过登录（本地模式）"**，此时进度只保存在本设备上，不会同步

## 📱 界面说明

### 📚 学习（主界面）
- 317 个主题词组（家庭、动物、食物、学校等）
- 每组 10 个单词 — 共 **3170 个单词**
- **每个希腊语单词上方都标有中文释义**，方便理解词义
- 彩色音节拼读：大写字母不带重音符号，**小写字母带重音符号**
- 点击卡片可将单词标记为「已学会」
- 每组都有进度条

### 🔤 ΑΒ — 字母表与语法
- **字母表：** 24 个希腊字母的大小写形式及读音名称，点击可听发音 🔊
- **双元音：** αι, ει, οι, υι, αυ, ευ, ου, ηυ — 先播放中文讲解，再自动播放希腊语示例发音
- **双辅音：** μπ, ντ, γκ, γγ, τσ, τζ — 同样先中文讲解，再自动播放希腊语发音
- **简明语法：** 7 条规则，先播放中文讲解，再自动播放希腊语例词发音

### 🔊 语音拼读功能
- 完成一个词组后，语音朗读功能会在 **7 天后**解锁
- 目的：让学习者先自己尝试阅读，之后再听发音确认
- 两个按钮：「🔊 音节」（逐个音节慢速朗读）和「🔊 单词」（完整朗读）

### 📖 故事
- **40 个希腊语小故事**，语言简单易懂
- **每个单词都可点击** — 点击任意单词即可听发音 🔊
- **每篇故事下方都有完整的中文翻译**，方便对照阅读
- 「朗读整个故事」— 自动逐句朗读

### 🔄 复习
- 所有已完成的词组会显示在这里
- 点击任意一组即可复习
- 显示语音功能是否已解锁，或还需等待几天

### ⭐ 进度
- 已学单词总数
- 已完成的词组数
- 总体学习进度百分比
- 账户信息与退出登录

## 🛡️ 隐私说明

| 情况 | 结果 |
|---|---|
| 同一账号登录多台设备 | 进度自动同步一致 |
| 其他人下载此应用 | 需要自己注册账号，看不到你的数据 |
| 没有网络时 | 应用正常使用，联网后自动同步 |
| 两台设备进度不同 | 智能合并 — 保留两边较多的学习记录 |
