📖 我在阅读！— 阅读与拼读学习应用
一款免费、离线可用的PWA应用，专为学习希腊语阅读与拼读的儿童设计。包含3170个单词，分为317个主题词组，配有语音拼读功能，并通过Firebase实现云端进度同步。

首次使用Firebase

打开应用 → 出现登录界面
点击**"创建账号"** → 输入邮箱和密码（6位以上字符）
在其他设备上：使用相同信息登录
登录后，输入孩子的姓名（例如"玛丽亚"）
应用会自动同步！


📱 界面与功能
登录界面

使用邮箱和密码登录
首次使用时创建账号
不登录继续使用（本地模式）

📚 学习（主界面）

317个主题词组（家庭、动物、食物、学校等）
每组10个单词 — 共计3170个单词
彩色拼读标注：大写字母不带重音符号，小写字母带重音符号
点击卡片将单词标记为"已学会"
每个词组的进度条

🔤 字母表 — 字母与语法

字母表： 全部24个字母的大小写形式，附希腊语名称。点击即可听发音 🔊
双元音： αι、ει、οι、υι、αυ、ευ、ου、ηυ — 发音方式及示例
双辅音： μπ、ντ、γκ、γγ、τσ、τζ — 发音方式及示例
简明语法： 7条为儿童设计的简单语法规则（重音符号、元音、辅音、词尾sigma、双字母组合、音节）

🔊 语音拼读

语音功能（希腊语TTS）在完成词组7天后解锁
目的：让孩子先自主阅读，然后通过听力进行确认
两个按钮：「🔊 音节」（缓慢逐个发音）和「🔊 单词」（完整发音）

📖 故事

30个短篇童话，用简单的希腊语讲述，适合儿童阅读
每个单词都可点击 — 点击任意单词即可听到发音 🔊
「听完整个故事」 — 逐句自动朗读

🔄 复习

所有已完成的词组都会显示在这里
点击任意一个进行复习
显示语音是否已解锁，或还需等待多少天

🛡️ 安全与隐私
场景会发生什么你本人（iPad + Android）使用相同邮箱登录 → 进度一致朋友下载了这款应用她拥有自己的账号 → 只能看到自己孩子的数据有人输入"玛丽亚"进入自己的账号 → 看不到你的数据没有网络连接本地运行，联网后自动同步两台设备进度不同智能合并 — 保留两者中较优的进度
